## Role we are hiring for

**Staff Software Development Engineer at Zscaler** builds and owns high-scale, security-critical software in Zscaler’s cloud (data plane, control plane, policy, networking, platform). This is an **IC Staff SDE** role — deep development ownership + multi-team technical leverage — not a manager role.

### What “good” looks like for this role
- Ships production systems in **Rust** (or equivalent systems language) at cloud scale
- Designs for **multi-tenant cloud security** (isolation, audit, fail-closed judgment)
- Owns outcomes: code, tests, metrics, incidents, remediation
- Raises the bar across teams via design, reviews, standards
- Thinks like a builder on a **cybersecurity cloud platform**, not a CRUD app team only
